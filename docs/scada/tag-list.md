## Load modes (`load_mode`)

| Value | Meaning |
|---|---|
| `none` | no load fitted |
| `off` | load fitted, both branches off (open circuit) |
| `hold` | holding the operating point of the last sweep |
| `sweep` | I-V sweep running (not expected in 10 s rows) |
| `trip` | fault: both branches off until the cause is gone |

## Alarm definitions

Priority 1 = high, 2 = medium, 3 = low. "Clears after" = rows in a row
without the condition before the alarm counts as cleared.

| Code | Priority | Group | Condition | Clears after | Text |
|---|---|---|---|---|---|
| `DET_NASIM` | 2 | detector | `alarm` bit `NASIM` | 1 | Thermal spike detected by NASIM-GBT |
| `DET_THRESHOLD` | 2 | detector | `alarm` bit `THRESHOLD` | 1 | Thermal spike detected by the threshold rule |
| `DET_CUSUM` | 2 | detector | `alarm` bit `CUSUM` | 1 | Thermal spike detected by the CUSUM |
| `RTC_INVALID` | 1 | system | `status` bit `RTC_INVALID` | 3 | RTC time invalid: rows logged without date and time |
| `TEMP_FAIL` | 1 | sensor | `status` bit `TEMP_FAIL` | 3 | Back-sheet temperature sensor not reading |
| `AMBIENT_FAIL` | 2 | sensor | `status` bit `AMBIENT_FAIL` | 3 | BME280: no ambient temperature |
| `IRRAD_FAIL` | 1 | sensor | `status` bit `IRRAD_FAIL` | 3 | PYR20: no irradiance |
| `PANEL_FAIL` | 1 | sensor | `status` bit `PANEL_FAIL` | 3 | Panel INA226: no voltage, current, power |
| `TROM_UNMAPPED` | 3 | system | `status` bit `TROM_UNMAPPED` | 3 | T_ROM not filled in: T1..T5 are not tied to module positions |
| `DET_RESET` | 2 | system | `status` bit `DET_RESET` | 1 | Detectors reset after 5 unusable rows: no detection for 10 min |
| `SD_ERROR` | 1 | system | `status` bit `SD_RETRY` | 3 | SD card write error: a retry was needed or rows were lost |
| `SD_OUTAGE` | 1 | system | `ring_rows` >= 30 (off at 0) | 3 | SD card not taking rows: lines wait in the logger's LittleFS ring |
| `RING_DROPPED` | 1 | system | `ring_dropped` >= 1 (off at 0) | 3 | Logger's LittleFS ring was full: lines were given up (data lost) |
| `LOAD_TRIP` | 1 | system | `load_mode` = `trip` | 1 | Measurement load tripped: both branches off |
| `NO_DATA` | 1 | system | no new row received for 60 s (PC clock) | 1 | No data arriving from the logger |

`DET_SKIPPED` is not an alarm: it follows from a sensor or RTC fault that
already alarms. The HMI shows it in the health panel.
